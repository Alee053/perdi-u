# Issue tracker: GitHub

New issues and PRs belong to `Alee053/perdi-u`; the shared sprint board is [PerdiU Backlog](https://github.com/users/Alee053/projects/5).

Historical issues and PRs remain in [Alee053/PerdiU](https://github.com/Alee053/PerdiU). Their numbers are not transferred: use full URLs or `Alee053/PerdiU#<number>` when referencing earlier work. Do not close or duplicate historical tickets automatically as part of a code migration.

Read new tickets with `gh issue view <number> --repo Alee053/perdi-u --comments`. Read the project with `gh project item-list 5 --owner Alee053`. Use existing issue labels and project statuses. Remote writes, pushes and PR creation require authorization from the current task.

Follow [CONTRIBUTING.md](../../CONTRIBUTING.md) for naming, PR templates, closing references, project linkage and review transitions; it is the shared source of these conventions.

PRs as a request surface: no.
